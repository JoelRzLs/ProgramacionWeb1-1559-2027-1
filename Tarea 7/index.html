RESUMEN HTML:PRINCIPALES CONCEPTOS Y ETIQUETAS

Esta pagina va a resumir los principales conceptos y etiquetas vistas en la clase de programacion web 1, en el modulo HTML

Conceptos principales HTML

HTML

El Lenguaje de Marcado de Hipertexto es un lengujae de marcas que se utiliza para estructurar sitios web

Elemento HTML

Un elemento HTML es la unidad básica de estructura y contenido en una página web, y esta compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head>

es una etiqueta que se utiliza para comunicarse con el navegador a traves de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semanticos

<header> Es una etiqueta utilizada para el contenido introductorio para una pagina web, puede contener el logo, el menu de navegacion principal, el nombre de la empresa, etc.
<NAV> Etiqueta utilizada para el menu de navegacion principal, suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal, no debe de haber mas de una en la pagina.
<MAIN> Etiqueta unica de una pagina web, cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra pagina
<SECTION> Es una etiqueta que poco a poco se intenta que sustituya a <DIV> , su uso es para dividir a una pagina web en secciones y agrupar contenido relacionado
<ARTICLE> Es una etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<FOOTER> Es una etiqueta que normalmente se encuentra hasta el final de una página y funciona cómo cierre de sitio web, amenudo contiene datos de contacto, derecho de autor u otra información complementaria
<ASIDE> Esta etiqueta representa una seccion de la pagina web cuyo contenido no esta relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces a otras paginas:

  • Externos
  • Internos
  • Anclaje

Algunosvalores especiales que tiene en su atributo href son:

href="https://wa.me/1234567891"
Este valor envia un WhatsApp a un numero especificado
href="mailto:example@gmail.com"
Envia un correo a un mail especifico

Elemento <form>

Es la forma en que los usuarios de un sitio web pueden comunicarse con el, mediante el formulario se reciben, procesan y envián datos de los usuarios para el fin u objetivo del sitio web
